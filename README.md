# Tic-Tac-Toe Game with Reinforcement Learning


## Description

This project is an interactive Tic-Tac-Toe game developed using **Streamlit** and **Python**. The game features a Q-learning agent that simulates intelligent gameplay, allowing players to compete against a dynamic AI. 

### Current Status: **In Progress**

This project is still under development, with several features planned for future implementation. Your feedback and contributions are welcome!

## Features

- **Interactive Gameplay**: Play against an AI that learns optimal strategies over time.
- **User-Friendly Interface**: An intuitive UI built with Streamlit for easy navigation and interaction.
- **Real-Time Feedback**: Players receive immediate feedback on their moves.
- **Game Reset Option**: Easily restart the game without refreshing the page.
- **Progressive Learning**: The Q-learning agent continuously improves its gameplay strategies.
